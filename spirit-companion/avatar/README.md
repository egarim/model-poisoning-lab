# Daemon avatar

Everything here is generated by code: no images, no animation tool.

| File | What it is |
|---|---|
| `tools/make_specs.py` | Writes the 16 daemon specs (8 archetypes x Latin American / Slavic forms) to `specs/` |
| `specs/*.json` | One daemon each: element, hue, body, eyes, and a list of parts built from the renderer's primitives |
| `renderer.js` | Draws any spec on a Canvas 2D context. Parts react to mood (approach A / inhibition I), bond stage (1-5) and state |
| `forge.template.html` | The Daemon Forge test page |
| `tools/build.py` | Inlines renderer and specs into `daemon.html` (one self-contained file) |
| `tools/contact_sheet.js`, `tools/grid.py` | Automated visual check: renders every daemon in 3 moods and 5 stages, reports errors, tiles contact sheets |

Primitives: ear (round, pointed, floppy), tail (bushy, rope, plume, curl, thin, stub, ringed), mane, muzzle, nose (cat, dog, round, with mouth and tongue), whiskers, paws, beard, hat, wing (butterfly, bat, feather, blur), antennae, crest (flame, feathers, plume),
antlers, wreath (leaves, flowers, berries), fronds, hair, fangs, beak (straight, hooked, stubby), dome, flippers, tentacles, tendrils, fin, charm; markings: rosettes, bark, blush, eyepatch, mask, tabby, calico, points, spots, belly, breast, cap, disc.

```bash
python3 tools/make_specs.py && python3 tools/build.py
node tools/contact_sheet.js daemon.html /tmp/qa && python3 tools/grid.py /tmp/qa
```

Porting to the app: replace the Canvas 2D calls in `renderer.js` with React Native Skia; specs stay as they are.

## Species and summoning

`species.js` adds real animals with real coats (12 species, 25 variants): red panda, panda, cat (7 coats), dog
(xoloitzcuintle, vira-lata caramelo, shiba, laika, golden, black), owl (brown, snowy), macaw (scarlet, hyacinth),
toucan, bullfinch, octopus, jellyfish, seal, capybara, plus the 16 folklore spirits.

`DaemonSpecies.summon(profile, folkSpecs)` turns a person into three candidates, seeded so the same person always
gets the same three:

| Input | Shapes |
|---|---|
| Birthplace | one creature from that country's pool (iconic ones more likely) and a talisman charm (MX marigold, BR ipê, AR ceibo, CO orchid, PE kantuta, CL copihue, RU rowan berries) |
| Birth date | zodiac element: aura and sigil colour |
| Energy (calm–energetic) | body proportions and how fast it moves; also picks the temperament wild card |
| Social (introvert–extrovert) | eye size and how open the gaze is |
| Guided by (heart–head) | blush for heart, more sigil points for head |
| Spirit (traditional–rebel) | a bent ear, or an unusual coat |
| All four | the archetype, i.e. the daemon's voice (Guardian, Trickster, Seer…) |

Each candidate carries the reasons it was summoned, shown to the user.

Visual check of every species: `node tools/species_sheet.js daemon.html /tmp/qa && python3 tools/species_grid.py /tmp/qa`.
